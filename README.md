# Parlons Français — تطبيق تعلّم الفرنسية

تطبيق ويب تفاعلي لتعلّم اللغة الفرنسية، مبني بـ **Next.js (App Router)** و **Tailwind CSS** و **Lucide React**.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:3000
```

للنشر: `npm run build && npm start`، أو ارفع المشروع إلى Vercel مباشرة.

## المميزات

- **لوحة التحكم**: المستوى الحالي (A1…C1)، شريط التقدم نحو المستوى التالي، الهدف اليومي، كلمة اليوم، والوحدات.
- **الدروس**: مفردات، قواعد، وتصريف الأفعال (Le Présent و Le Passé Composé) مع أمثلة وأزرار نطق.
- **الاختبارات**: اختيار من متعدد + إكمال الفراغ، تصحيح فوري، شرح، ومؤثرات صوتية (Web Audio).
- **الاستماع** (`/listening`): إملاء صوتي، يُنطق جملة فرنسية ويكتبها المتعلم، مع إبراز الكلمات الخاطئة والتنبيه لعلامات التشكيل.
- **مراجعة الأخطاء** (`/review`): تُحفظ الأسئلة الخاطئة تلقائياً وتُعاد حتى تُجاب بشكل صحيح.
- **المستويات A1 إلى C2**: 57 درساً و21 اختباراً و48 جملة استماع. الدروس الإضافية في `lib/content-a1a2.js` (A1–A2) و`lib/content-b1.js` (B1) و`lib/content-b2.js` (B2).
- **المستوى بالإتقان**: يُحسب المستوى من الدروس المكتملة والاختبارات المجتازة (70٪ فأكثر)، لا من النقاط. النقاط (XP) للتحفيز فقط. المنطق في `lib/mastery.js`.
- **اختبار تحديد المستوى** (`/placement`): 20 سؤالاً من A1 إلى C1، والمستويات التي تسبق نتيجتك تُحتسب منجزة. الأسئلة في `PLACEMENT_QUESTIONS` داخل `lib/data.js`.
- **محاكاة TCF IRN** (`/exam`): فهم مسموع (20 سؤالاً، 15 دقيقة) وفهم مقروء (20 سؤالاً، 20 دقيقة)، وكتابة (30 دقيقة، 3 مهام بصيغة: وصف شيء، سرد أنشطة، إبداء رأي — `lib/ee-data.js`) وشفهي (10 دقائق، 3 أسئلة) حسب بطاقة France Compétences RS6643. تُسحب 20 سؤالاً من بنك من 62 لكل قسم في كل محاولة، مع تجنب ما مرّ عليك، بمؤقت ووضعي امتحان (سماع واحد) وتدريب. الأسئلة أصلية في `lib/exam-data.js` وليست رسمية، والتقدير غير رسمي.
- **بطاقات المفردات** (`/flashcards`): تكرار متباعد (Leitner) من مفردات الدروس تلقائياً (`lib/srs.js`)، بحد 10 بطاقات جديدة يومياً.
- **خطة اليوم** (`/plan`): مهام يومية حسب تقدمك (درس، اختبار، بطاقات، أخطاء، استماع، كتابة) وتقدير تقريبي لجاهزية B2.
- **الامتحان المدني** (`/civic`): 40 سؤالاً أصلياً (امتحان كامل بنجاح عند 80٪، أو تدريب سريع 10 أسئلة). الأسئلة في `lib/civic-data.js` وتحتاج مراجعة مع المصادر الرسمية (livret du citoyen).
- **التعبير الكتابي** (`/writing`): 8 مواضيع من A1 إلى B2 مع تلميحات آلية بسيطة (كلمات متوقعة وعدد الكلمات) ونموذج إجابة. لا يصحّح القواعد ولا الإملاء.
- **خطة المحتوى الناقص**: انظر `CONTENT_ROADMAP.md`.
- **PWA**: تثبيت على الشاشة الرئيسية وعمل دون اتصال (Service Worker في `public/sw.js`، يُسجَّل في وضع الإنتاج فقط).
- **التذكير اليومي**: إشعار من المتصفح في وقت تحدده إن لم تدرس اليوم. يعمل والتطبيق مفتوح؛ الإشعارات مع التطبيق مغلقاً تحتاج خادم Push.
- **النطق**: Web Speech API (SpeechSynthesis) مع سرعة عادية/بطيئة واختيار الصوت.
- **المكافآت**: نقاط XP وسلسلة أيام متتالية (Streak)، محفوظة في `localStorage`.
- **الوضع الليلي/النهاري** وتصميم متجاوب (هاتف، لوحي، حاسوب) مع واجهة RTL.

## إضافة محتوى جديد

كل المحتوى في `lib/data.js`:

- **درس جديد**: أضف كائناً إلى `LESSONS` (`vocab` و/أو `rules` و/أو `conjugation`).
- **اختبار جديد**: أضف كائناً إلى `QUIZZES`. نوع `mcq` يحتاج `options` و `answer` (رقم الخيار الصحيح)، ونوع `fill` يحتاج `prompt` يحتوي `___` و `answer`.

## ملاحظات

- النطق يعتمد على أصوات المتصفح/النظام. إن لم يوجد صوت فرنسي ثبّته من إعدادات نظام التشغيل.
- التقدم محفوظ في المتصفح فقط (لا يوجد خادم أو حساب مستخدم).

- المحاكاة تتجنب تكرار المواضيع في الإعادة (`lib/rotation.js`، تُحفظ المواضيع التي مرّت في المتصفح).
